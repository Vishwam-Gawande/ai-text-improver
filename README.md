# 🔥 AI Text Improver

A simple AI-style web app built using Python and Streamlit.

## 🚀 Features
- Improve text in multiple styles:
  - Formal
  - Friendly
  - Concise
- Clean and simple UI
- Real-time processing

## 🌐 Live Demo
https://ai-text-improver-pnpu9ysktcj2uvcudcsxfy.streamlit.app/

## 🛠️ Tech Stack
- Python
- Streamlit

## 📌 How it works
- User enters text
- Selects mode
- System processes text using rule-based logic
- Displays improved output
